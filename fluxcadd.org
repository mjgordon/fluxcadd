* Implementation Notes
** m3d.transformPosition vs v3d.mulPosition:
- m4d.transformPosition: Calculates transformation directly
- v3d.mulPosition: Includes initial checks for if the matrix is an identity or translation matrix. In a full transformation, calculation is wrapped in multiple Math.fma() calls.
